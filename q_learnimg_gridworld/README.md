# Q-Learning GridWorld

A small tabular Q-learning experiment built as a bridge from introductory reinforcement learning to Deep Q-Learning.

## Environment

```text
4×4 grid
Start:  state 0
Goal:   state 15
Walls:  states 5 and 10

Actions: UP, DOWN, LEFT, RIGHT
Normal move: -1
Obstacle:    -10
Goal:        +10
```

## Q-learning setup

- Episodes: 500
- Learning rate (α): 0.10
- Discount factor (γ): 0.99
- Initial exploration (ε): 1.0
- ε decay: 0.995
- Minimum ε: 0.01
- Random seed: 42

The Q-table is saved after training as `data/q_table_500_episodes.npy`. The final greedy policy and training history are also saved for inspection.

## Run

From this directory:

```bash
pip install -r requirements.txt
python train_q_learning.py
python download_sprite.py
python visualize_q_learning.py
```

The visualization loads the saved Q-table and animates the learned greedy policy from the start state to the goal.

## Learning rule

For a non-terminal transition:

`target = reward + gamma * max(Q[next_state])`

For a terminal transition:

`target = reward`

Then:

`Q[state, action] += alpha * (target - Q[state, action])`

This is the tabular Q-learning update that this project is intended to make concrete before moving to Deep Q-Networks.
